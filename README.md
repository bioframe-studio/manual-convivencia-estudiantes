# Manual de Convivencia 2026 · Versión para estudiantes

Flipbook interactivo del Manual de Convivencia de la Institución Educativa Compartir, para estudiantes de Transición a 5.° y de 6.° a 11.°.

- Abre `index.html` (funciona sin internet).
- Flechas ← → o AvPág/RePág para pasar la página · N: notas para el docente · I: índice · F: pantalla completa.

Es una versión pedagógica: ante cualquier duda, prevalece el Manual de Convivencia completo.
